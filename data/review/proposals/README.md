# Sanitized review proposals

Files in this directory are maintainer-generated, structured proposals. They are not analyst decisions and do not change the public Radar dataset.

The manual workflow accepts only controlled fields, validates a fully defanged domain, links to a public issue by number, and creates a draft pull request. It never reads or executes issue text. A maintainer must independently verify the evidence and use the private append-only review ledger before a sanitized decision can be exported.
