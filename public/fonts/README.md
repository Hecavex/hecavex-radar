# HECAVEX type assets

The production interface at `radar.hecavex.com` self-hosts the Latin and Latin Extended subsets of Inter and IBM Plex Mono. The files are sourced from Fontsource 5.3.0 and are distributed under the SIL Open Font License 1.1.

- Inter is used for interface and reading text.
- IBM Plex Mono is used for evidence, labels, timestamps, URLs and compact navigation.

The complete license texts are stored beside this file as `INTER-OFL.txt` and `IBM-PLEX-MONO-OFL.txt`.
